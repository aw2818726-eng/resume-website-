SQL & Data Cleaning Practice — BigQuery

Practice against a real dataset: querying, aggregation, joins, subqueries/CTEs, and window functions, plus a structured cleaning checklist.

Project: my-first-pro-504117.cars.cars

Aggregation

SELECT manufacturer, AVG(price) AS avg_price
FROM `my-first-pro-504117.cars.cars`
GROUP BY manufacturer ORDER BY avg_price DESC;

CTE

WITH mfr_avg AS (
  SELECT manufacturer, AVG(price) AS avg_price
  FROM `my-first-pro-504117.cars.cars` GROUP BY manufacturer
)
SELECT c.manufacturer, c.model, c.price
FROM `my-first-pro-504117.cars.cars` c
JOIN mfr_avg ON c.manufacturer = mfr_avg.manufacturer
WHERE c.price > mfr_avg.avg_price;

Window function

SELECT manufacturer, model, price,
  RANK() OVER (PARTITION BY manufacturer ORDER BY price DESC) AS price_rank
FROM `my-first-pro-504117.cars.cars`;

Data cleaning pass

-- flag rows missing key fields
SELECT * FROM `my-first-pro-504117.cars.cars`
WHERE price IS NULL OR manufacturer IS NULL;

-- find duplicate listings
SELECT manufacturer, model, price, COUNT(*) AS dupes
FROM `my-first-pro-504117.cars.cars`
GROUP BY manufacturer, model, price HAVING COUNT(*) > 1;
